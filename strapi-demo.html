How this page is actually wired

The cards above aren't hardcoded HTML — they're rendered from an array shaped exactly like Strapi's REST response. Point API_URL below at a real Strapi instance and the mock array disappears.

01 — Model the content

Define a content type

In the Strapi admin, create an "Article" collection with fields: title, excerpt, body, cover image, category, author.

npx create-strapi-app@latest signal-cms
cd signal-cms && npm run develop
02 — Fetch it from the front end

Call the REST API

This is the real fetch this page would use once a Strapi server is running locally.

const res = await fetch(
  'http://localhost:1337/api/articles?populate=*'
);
const { data } = await res.json();
